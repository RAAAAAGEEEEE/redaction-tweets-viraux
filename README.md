# redaction-tweets-viraux

Claude Code skill pour la rédaction de tweets et threads viraux : style direct, frontal et punchy.

## Installation

Copier le dossier `redaction-tweets-viraux` dans `~/.claude/skills/`.

Version 1.1.0 (2026-09-28), voir [CHANGELOG.md](CHANGELOG.md).

Pour des tweets en français, installer aussi le skill
[redaction](https://github.com/RAAAAAGEEEEE/claude-skill-redaction)
(langue, typographie, relecture).
