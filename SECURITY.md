# Sécurité

## Surface

Ce skill ne fait aucun accès réseau, ne publie rien et ne stocke rien : `scripts/verifier.py` lit un fichier local ou l'entrée standard. Voir [docs/PRIVACY_AND_SECURITY.md](docs/PRIVACY_AND_SECURITY.md).

## Signaler un problème

Le signalement privé de GitHub (« Report a vulnerability ») n'est pas activé sur ce dépôt. Ouvrir une [issue](https://github.com/RAAAAAGEEEEE/redaction-tweets-viraux/issues/new) intitulée « Sécurité » **sans détail exploitable** ni donnée personnelle ; le mainteneur répondra pour convenir d'un canal privé.

## Versions concernées

Seule la dernière version publiée (voir [CHANGELOG.md](CHANGELOG.md)) reçoit des correctifs.
