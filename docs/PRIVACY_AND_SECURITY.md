# Confidentialité et sécurité

## Ce qui sort de la machine

Rien, du fait de ce dépôt.

- `scripts/verifier.py` lit un fichier local ou l'entrée standard, écrit sur la sortie standard, n'ouvre aucune connexion réseau et ne stocke rien.
- Aucun réseau social n'est appelé : le skill rédige, l'utilisateur publie.
- Les textes que vous donnez à Claude suivent le régime de confidentialité de votre offre Claude ; ce dépôt n'y ajoute rien.

## Bonnes pratiques

- Ne pas coller dans un brief des données personnelles de tiers (noms de clients, e-mails, conversations privées) que vous ne comptez pas publier.
- Ne pas mettre de clé d'API, de jeton ou de mot de passe dans un fichier de posts.
- Un post publié est public : relire les `[[à confirmer]]` avant de publier ; le vérificateur les signale.
